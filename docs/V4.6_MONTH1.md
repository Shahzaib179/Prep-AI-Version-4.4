# Prep AI v4.6 – Month 1 features

All four Month-1 items are now in the app. No new packages or secrets are needed; database changes apply automatically on start (migrations 5–7).

## 1. Question bank (tutors; students for AI-saved questions)
Tutor Dashboard → **Question Bank**: add questions by hand, upload/download CSV, search and filter, edit, delete, tick *shared* so students can use them in mock tests, and build a quiz from the bank. Duplicates are detected by question text.

## 2. Question editing and option shuffling
- Edit any question in the bank, or review/edit before publishing (✏️ in the Publish tab).
- Published quizzes shuffle options per student (switch it off when publishing). The shuffle is stable for each student and the correct answer is remapped. Questions with options such as "All of the above" are never shuffled.

## 3. Tutor classes with deadlines
- Tutor Dashboard → **Classes**: create a class (6-character code), see/remove members, assign a published quiz with a due date and time, optionally allow late starts, change the deadline, download a CSV report, see who has not finished.
- Students: **My Classes** in the sidebar (shows a count of pending assignments): join by code, see every assignment with its status, press Start.
- Rule: a student must **start** the quiz before the deadline. After it, starting is refused, unless the tutor allowed late starts (then the result is flagged "done late"). Students who are not in the class are not affected.
- Times are entered and shown in the app's timezone (`PROGRESS_TZ_OFFSET_MIN`, default UTC+5).

## 4. Mock test mode
Student → **Mock Test**.
- Types: MDCAT-style 200 questions / 210 min (Biology 68, Chemistry 54, Physics 54, English 18, Logical Reasoning 6, no negative marking), shorter versions, or Custom counts. Time and negative marking (−0.25) can be changed.
- Questions come from your bank first (unseen ones first). Missing ones can be filled by AI (you set a maximum); AI questions are saved to your bank, so the next mock needs fewer.
- Sectioned tabs, live timer, answers saved automatically; a refresh or closed browser can be resumed and the clock keeps running. Auto-submit at time-up.
- Result: marks, percentage, per-section scores, advice on what to focus on, review of wrong answers, and a history chart under **My mock results**. Results also feed XP, streak, mistakes and mastery per subject.

## Before going live
Run `scripts/verify_postgres.sh` against a staging database (the Postgres path is covered by tests written for it but has not been run against a real Postgres in development). The migration script now also copies the bank, class, assignment and mock tables.
